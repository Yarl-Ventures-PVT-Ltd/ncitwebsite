# 🌐 NCIT - Northern Chamber of Information Technology

> **Northern Sri Lanka’s Gateway to Technology, Talent & Global Opportunity.**

Welcome to the official repository for the **NCIT Website Rebuild (2026)**. This platform connects companies, professionals, educators, startups, freelancers, students, investors, government, and development partners across Jaffna, Kilinochchi, Mannar, Mullaitivu, and Vavuniya to build a stronger, globally connected digital economy.

---

## ✨ Features

- **Premium Modern UI/UX:** Stunning, glassmorphism-inspired design with crisp typography and subtle micro-interactions.
- **Interactive Ecosystem Dashboard:** A dynamic, state-driven UI to explore the technological strengths of the 5 Northern districts.
- **Bento Grid Architecture:** Beautifully structured data visualization for stakeholders using modern CSS grid layouts.
- **Fully Responsive:** Mobile-first architecture ensuring perfect layouts across all devices, from phones to ultra-wide monitors.
- **High Performance:** Built on the bleeding edge of web technologies for lightning-fast page loads and SEO optimization.

---

## 🛠️ Tech Stack

This project is built using the most modern frontend stack available:

- **Framework:** [Next.js 15](https://nextjs.org/) (App Router)
- **Library:** [React 19](https://react.dev/)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/)
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Components:** Custom headless UI components inspired by modern design systems.

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the repository
```bash
git clone git@github.com:Yarl-Ventures-PVT-Ltd/ncitwebsite.git
cd ncitwebsite
```

### 2. Install dependencies
Make sure you have Node.js installed, then run:
```bash
npm install
```

### 3. Run the development server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to see the application running.
